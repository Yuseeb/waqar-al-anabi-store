# WAQAR AL ANABI

A responsive static storefront starter for WAQAR AL ANABI.

## Before launch
- Replace the sample product names, prices and photos with your real catalogue.
- Replace the placeholder WhatsApp number in the page source with your business number (country code + digits).
- Update social links and contact details.
- Test the checkout flow on mobile.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder /(root), then Save.
4. Wait for the published URL to appear.

## Important
This is a static demo storefront. The cart is browser-side and checkout opens WhatsApp. It does not include customer accounts, a database, online card payments, inventory sync, or an admin dashboard.
